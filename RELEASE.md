# Release process

The project is pre-release and Phase 1 is development-only. There are no signed binaries or production installer.

Every phase gate requires clean lint, formatting, typecheck, unit tests, integration tests, and builds, plus updated architecture/security documentation and a phase report listing known limitations. A production release additionally requires security review, end-to-end Chrome tests, installer repair/uninstall verification, dependency inventory, signed artifacts, and rollback instructions.
