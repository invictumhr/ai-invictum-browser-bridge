# Windows installation

There is no production installer in Phase 1. The current build is for development only and is not packaged with Node.js, Tauri, or a signed native-host executable.

Use [EXTENSION_INSTALL.md](EXTENSION_INSTALL.md) for the temporary per-user development registration. Phase 7 will add install, repair, upgrade, uninstall, policy preservation, Start Menu integration, and opt-in autostart without opening public firewall ports.
