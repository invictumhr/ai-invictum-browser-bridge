# Support

Invictum Browser Bridge is an open-source developer preview. Community support
is provided through the GitHub repository.

## Before opening an issue

1. Read the [Quick start](README.md#quick-start) and
   [Troubleshooting](TROUBLESHOOTING.md) guides.
2. Run `pnpm browser health`, `pnpm browser ping`, and
   `pnpm browser capabilities`.
3. Confirm Chrome is running, the unpacked extension is enabled, and Native
   Messaging is installed.
4. Reproduce the problem on a non-sensitive page or repository fixture when
   possible.
5. Search existing issues.

## Where to ask

- Use the
  [bug report](https://github.com/invictumhr/ai-invictum-browser-bridge/issues/new?template=bug_report.yml)
  for reproducible failures.
- Use the
  [feature request](https://github.com/invictumhr/ai-invictum-browser-bridge/issues/new?template=feature_request.yml)
  for new typed actions, platform adapters, or ergonomics improvements.
- Use
  [GitHub private vulnerability reporting](https://github.com/invictumhr/ai-invictum-browser-bridge/security/advisories/new)
  for security issues.

Include versions, the smallest reproduction, expected behavior, and sanitized
error codes. Do not include passwords, tokens, cookies, private keys, local
file paths, URL credentials, production page content, or raw terminal output.

## Scope

The project can help with IBB installation, runtime behavior, supported browser
actions, documented WordPress/terminal/Figma adapters, and reproducible defects.
General website administration, server operations, and third-party product
support remain outside the project's support scope.
