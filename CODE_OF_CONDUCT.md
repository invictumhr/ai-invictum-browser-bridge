# Code of Conduct

## Our commitment

We want participation in Invictum Browser Bridge to be a safe, respectful, and
productive experience for everyone, regardless of background, identity,
experience level, or role in the project.

## Expected behavior

- Be respectful, specific, and constructive.
- Discuss technical decisions and observable behavior rather than attacking
  people.
- Respect privacy. Never publish credentials, cookies, tokens, private URLs,
  production administration screens, or other sensitive data.
- Give contributors room to learn and correct mistakes.
- Accept maintainers' decisions about security boundaries, user control, and
  responsible disclosure.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Publishing another person's private information without permission.
- Deliberately bypassing project safeguards or encouraging unsafe use.
- Spam, manipulation, or sustained disruption of project spaces.

## Enforcement

Maintainers may edit or remove contributions that violate this code and may
temporarily or permanently restrict participation. Report conduct concerns to
the project maintainers through their GitHub profiles. Do not use a public
issue when a report contains private or sensitive information.

Security vulnerabilities must be reported through
[GitHub private vulnerability reporting](https://github.com/invictumhr/ai-invictum-browser-bridge/security/advisories/new).
